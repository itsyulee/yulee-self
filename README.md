## Installation

### Windows

```bash
curl -o "%TEMP%\install_yuleeself.bat" https://raw.githubusercontent.com/itsyulee/yulee-self/main/install_yuleeself.bat && "%TEMP%\install_yuleeself.bat"
```

### Termux / Linux / MacOS

```bash
bash <(curl -s https://raw.githubusercontent.com/itsyulee/yulee-self/main/install_yuleeself.sh)
```

#### For Termux

Make sure to install the **Termux** and **Termux:API** apps from F-Droid or GitHub (grant the API app notifications permission). After the installation script finishes, follow the setup steps prompted by `setup.py`. If you face issues with the basic installation, try the manual installation method.
