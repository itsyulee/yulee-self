CAP NHAT THUONG HIEU YULEESELF

1. Tat chuong trinh dang chay va sao luu thu muc project hien tai.
2. Giai nen file ZIP vao thu muc project (cung noi voi setup.py).
3. Chap nhan thay the cac file trung ten. Khong xoa thu muc project cu.
4. Chay lai python setup.py, sau do nhan Ctrl+F5 tren trinh duyet.

Goi nay chi chua 15 file ma nguon da sua; khong chua hay ghi de config/, data/, tai khoan, mat khau, token.
Ten module, class, CSS selector, thu muc icon va co so du lieu cu duoc giu de tuong thich.
Thong tin tac gia goc va giay phep duoc giu nguyen.
Canh bao desktop mac dinh cu se hien thi YULEESELF; tieu de tu dat duoc giu nguyen.
Bo cai van giu ten install_neuraself.bat/.sh de tuong thich, nhung cai YULEESELF tu repo itsyulee/yulee-self va chay setup.py.
Da tat kiem tra version tu repo goc de tranh yeu cau quay ve NeuraSelf. Neu can, cau hinh YULEESELF_VERSION_URL voi version feed rieng.

Da kiem tra cu phap Python, JavaScript (gom script login), Bash va duong dan asset trong HTML.
Chua chay ket noi Discord hay kiem thu bo cai tren Windows.
Chua push len GitHub; can cap nhat cac file len repo truoc khi dung lenh cai tu xa trong README.
